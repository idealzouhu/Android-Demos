### UI 导航模式

| 导航模式 | 组件                  | 应用场景                 |
| -------- | --------------------- | ------------------------ |
| 底部导航 | BottomNavigationView  | 3-5个主要功能模块        |
| 顶部 Tab | TabLayout + ViewPager | 同一模块下的子分类       |
| 侧滑菜单 | DrawerLayout          | 功能菜单、设置、用户中心 |
| 悬浮按钮 | FloatingActionButton  | 主要操作                 |
| 导航抽屉 | NavigationRail        | 大屏适配                 |
